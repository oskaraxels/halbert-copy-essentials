# Halbert Copy Essentials

A single-page learning site: Gary Halbert's route to becoming a copywriter, turned into narrated modules with read-along text, application questions, hands-on drills, a type-out pad and a portfolio workbook.

Sources: Hopkins, Caples, Schwab, The Gary Halbert Letter, The Boron Letters, Schwartz, Sugarman, Ogilvy, Collier, and Meta's and Google's own creative guidance. All lessons are written in our own words; quotes are short and attributed, and every source is linked on the Sources page. No book text is reproduced, and classic ads are linked rather than copied.

Progress is saved only in your browser (localStorage). Audio narration is synthetic.
